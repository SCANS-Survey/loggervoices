Logger Voice Recording

Overview

During line transect surveys it's sometimes helpful to record audio from the observers. This enables offline checking of data, particularly when multiple groups of animals are around and the data recorder struggles to enter all relevant data in real time.

Following on from the methods developed for the 2005 SCANS survey, described in Gillespie, Leaper, et al., 2010 this plugin PAMGuard modules allows voice recording, triggered by logger buttons and the SCANS app.

Note that this module can only receive audio data via the SCANS app, and does not work with standard sound cards.

All data are stored as 16 bit, 8kHz, mono files from each SCANS app platform.
